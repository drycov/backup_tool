Группы задают SSH-логин, пароль и модель Oxidized для устройств с одинаковым полем group. Сохраняются в БД и синхронизируются в oxidized/config → секция groups.

Профиль — имя записи в системе (напр. ovn). Группа — ключ для устройств (напр. hex из network_inventory.yml). Стандартный набор после import: профиль ovn → группа hex, профиль us → группа us.
