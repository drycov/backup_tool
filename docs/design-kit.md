# Design kit

Статический UI Backup Tools подключается к [@drycov/design-kit](https://github.com/drycov/design-kit).

В `scanner/static/index.html` добавьте **перед** `style.css`:

```html
<link rel="stylesheet" href="/static/css/design-kit.css" />
<html data-tg-theme="dark">
```

Файл: `scanner/static/css/design-kit.css`.
